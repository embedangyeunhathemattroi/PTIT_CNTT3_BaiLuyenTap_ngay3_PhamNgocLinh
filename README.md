# Website Trung tâm Tiếng Anh TTA

## Giới thiệu

Website của **Trung tâm Tiếng Anh TTA** giúp học viên *tìm hiểu khóa học và đăng ký học trực tuyến*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| data/ | Lưu dữ liệu học viên và bảng học phí. |
| docs/ | Lưu tài liệu của dự án. |
| media/ | Lưu hình ảnh và các tệp đa phương tiện. |

## Quy trình đăng ký học

1. Tìm hiểu các khóa học tại trung tâm.
2. Chọn khóa học phù hợp và điền thông tin đăng ký.
3. Xác nhận đăng ký và thanh toán học phí.

## Liệt kê nội dung dự án

Chạy lệnh sau trong PowerShell tại thư mục gốc dự án:

```powershell
Get-ChildItem -Recurse -Force
```
